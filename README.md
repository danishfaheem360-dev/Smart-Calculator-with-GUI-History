🧠 Smart Calculator in C++

This is an interactive console-based calculator written in C++.
It performs basic arithmetic operations and keeps a history of your last calculations, making it both practical and impressive for learning and demonstration purposes.

🚀 Features

Basic Arithmetic: Addition, Subtraction, Multiplication, Division

History Support: View the last 5 calculations anytime by entering h

Error Handling: Prevents division by zero and invalid input

Interactive Console UI: Easy-to-use and beginner-friendly

🛠️ Technologies Used

C++ (C++11 or later recommended)

Standard C++ Library (iostream, vector, string)

📂 Project Structure
smart-calculator-cpp/
│
├── calculator.cpp     # Main C++ source file
└── README.md          # Project description

▶️ How to Run

Make sure a C++ compiler is installed (e.g., g++, clang, or Visual Studio).

Clone this repository:

git clone https://github.com/your-username/smart-calculator-cpp.git


Navigate to the project folder:

cd smart-calculator-cpp


Compile the program:

g++ calculator.cpp -o calculator


Run the program:

./calculator   # On Linux/Mac
calculator.exe # On Windows


Start calculating! 🎉

🧩 How It Works

Enter the first number

Enter the operator (+, -, *, /)

Enter the second number

The program displays the result and stores it in history

Type h to see the last 5 calculations

Type q to quit the program
